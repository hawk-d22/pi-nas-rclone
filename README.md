# pi-nas-rclone

Home page and privacy policy for the personal Google OAuth client that rclone on
my Raspberry Pi uses to sync my own Google Drive. Google requires both links
before an External OAuth app can be published.

Served with GitHub Pages:

- Home page: https://hawk-d22.github.io/pi-nas-rclone/
- Privacy policy: https://hawk-d22.github.io/pi-nas-rclone/privacy.html

No credentials or configuration are stored in this repository.
